# MacNotch
Standalone installer: push to GitHub, run Actions > "Build MacNotch installer", download the .exe artifact (bundles WebView2, no admin).
Features: notch (media), menu bar (acrylic), dock that replaces the Windows taskbar (running apps, pin/unpin, magnify, auto-hide),
Control Center (Wi-Fi/Bluetooth toggles + Wi-Fi network list, brightness, volume), Launchpad, Settings window.
If the Windows taskbar ever stays hidden after a crash: run MacNotch again and click Quit, or Task Manager > restart "Windows Explorer".
Not yet: notifications, widgets, left/right dock position.
